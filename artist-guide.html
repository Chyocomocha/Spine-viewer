Spine Portfolio

아티스트용 사용 설명서

이 문서는 코드를 모르는 아티스트가 로컬에서 포트폴리오 데이터를 편집하고, 확인하고, GitHub Pages에 올리는 흐름을 설명합니다.

관리자 열기 포트폴리오 보기

가장 중요한 원칙

작품 설명, 그룹, 이름, 숨김 여부 같은 포트폴리오 내용은 data/portfolio.json에 저장됩니다. 레이아웃 파일을 고치지 않아도 관리자 화면에서 대부분의 내용을 수정할 수 있습니다.

1. 가장 빠른 사용 순서

  1. 실행 파일\edit-portfolio.bat를 더블클릭합니다.
  2. 브라우저에 관리자 화면이 열리면 왼쪽 목록에서 그룹 또는 작업물을 선택합니다.
  3. 텍스트를 수정합니다. 수정 후 잠시 기다리면 자동 저장됩니다.
  4. 상단의 보기 버튼으로 공개 페이지를 확인합니다.
  5. 전부 확인했으면 실행 파일\publish-portfolio.bat를 더블클릭해 GitHub Pages로 올립니다.

서버 창을 닫으면 자동 저장이 멈춥니다. 편집하는 동안에는 검은색 서버 창을 닫지 않는 것이 좋습니다.

2. 관리자 화면 구성

상단 영역

전체 설정, 공개 페이지 보기, 다시 불러오기, 즉시 저장 버튼이 있습니다. 저장 상태도 바로 아래에 표시됩니다.

왼쪽 목록

그룹과 작업물/캐릭터가 계층으로 보입니다. 그룹 헤더를 누르면 그룹 정보, 작업물을 누르면 작업물 설명 편집이 열립니다.

가운데 편집 영역

선택한 대상에 따라 그룹 정보 레이어 또는 작업물/캐릭터 설명 레이어가 나타납니다.

오른쪽 저장 상태

자동 저장 가능 여부, 데이터 오류, 경고를 확인합니다. 오류가 있으면 저장이 멈출 수 있습니다.

3. 상단 버튼 역할

버튼 하는 일 언제 쓰나 주의점
전체 설정 포트폴리오 전체 제목, 부제목, 소개글, 처음 열 작업물을 수정하는 패널을 열고 닫습니다. 사이트 제목을 바꾸거나, 첫 화면에 어떤 작품이 뜰지 정할 때 씁니다. 작업물 하나의 설명을 바꾸는 곳이 아닙니다.
사용 설명서 지금 보고 있는 이 설명서를 엽니다. 버튼 의미가 헷갈리거나 작업 순서를 확인할 때 씁니다. 설명서는 보기용입니다. 여기서 데이터를 수정하지 않습니다.
보기 공개 포트폴리오 화면을 엽니다. 수정한 내용이 실제 페이지에서 어떻게 보이는지 확인할 때 씁니다. 자동 저장이 끝난 뒤 확인해야 최신 내용이 보입니다.
다시 불러오기 data/portfolio.json을 다시 읽어 현재 화면을 갱신합니다. 파일을 외부에서 수정했거나 화면 상태가 이상할 때 씁니다. 저장되지 않은 변경사항은 사라질 수 있습니다. 확인창이 뜨면 신중히 선택하세요.
지금 저장 자동 저장을 기다리지 않고 즉시 저장합니다. 닫기 전, 게시 전, 중요한 변경 후 바로 저장하고 싶을 때 씁니다. 오른쪽 저장 상태에 오류가 있으면 저장되지 않을 수 있습니다.

4. 전체 설정 패널

전체 설정을 누르면 포트폴리오 전체에 적용되는 정보만 수정합니다. 특정 캐릭터 설명은 여기서 바꾸지 않습니다.

항목 의미 작성 팁
포트폴리오 제목 공개 페이지 왼쪽 상단에 가장 크게 보이는 사이트 이름입니다. 작가명, 프로젝트명, 또는 Spine Portfolio처럼 짧고 명확하게 씁니다.
부제목 제목 아래에 붙는 짧은 설명입니다. 예: Spine Animator, Technical Artist처럼 역할을 적기 좋습니다.
소개글 포트폴리오 전체 소개 데이터입니다. 레이아웃 확장용 데이터입니다. 현재 공개 화면에서 크게 보이지 않아도 지우지 않아도 됩니다.
처음 열 작업물 공개 페이지를 처음 열었을 때 자동으로 선택될 작업물입니다. 가장 보여주고 싶은 대표 작업물을 고르세요. 숨김 처리한 작업물은 피하는 것이 좋습니다.

5. 왼쪽 목록 버튼과 클릭 영역

영역 하는 일 주의점
그룹 추가 새 그룹을 만듭니다. 그룹은 공개 페이지 왼쪽 목록의 큰 묶음입니다. 추가 후 그룹 이름과 ID를 확인하세요.
작업물 추가 현재 선택된 그룹 안에 새 작업물/캐릭터를 추가합니다. 추가 후 HTML 파일 이름을 정확히 넣어야 공개 페이지에서 로드됩니다.
그룹 헤더 클릭 가운데에 그룹 정보 레이어를 엽니다. 그룹 이름이나 그룹 설명을 바꿀 때 사용합니다. 작업물 설명 편집과는 다릅니다.
작업물/캐릭터 클릭 가운데에 작업물/캐릭터 설명 편집 레이어를 엽니다. 현재 공개 페이지에 보이는 설명은 여기서 바꿉니다.

6. 그룹 정보 레이어

왼쪽에서 그룹 헤더를 누르면 열립니다.

항목 의미 주의점
그룹 삭제 선택한 그룹을 삭제합니다. 그룹 안의 작업물도 함께 사라집니다. 임시로 안 보이게 하려면 삭제보다 숨김을 사용하세요.
그룹 이름 공개 페이지 왼쪽 목록에 보이는 그룹 이름입니다. 아티스트가 보는 제목이므로 자유롭게 써도 됩니다.
ID (고급) 데이터 내부에서 쓰는 고유 이름입니다. 가능하면 영어 소문자, 숫자, 하이픈만 사용하세요. 이미 쓰는 ID와 중복되면 안 됩니다.
그룹 설명 그룹에 대한 설명 데이터입니다. 현재 공개 화면에서는 그룹 설명을 크게 보여주지 않습니다. 향후 레이아웃 확장용으로 남겨둘 수 있습니다.
공개 페이지에서 숨김 체크하면 이 그룹을 공개 페이지 목록에서 숨깁니다. 삭제가 아니라 숨김입니다. 다시 체크를 해제하면 보일 수 있습니다.

7. 작업물/캐릭터 설명 레이어

왼쪽에서 작업물/캐릭터를 누르면 열립니다.

버튼/항목 하는 일 주의점
위로 선택한 작업물을 같은 그룹 안에서 한 칸 위로 올립니다. 공개 페이지 왼쪽 목록 순서에도 영향을 줍니다.
아래로 선택한 작업물을 같은 그룹 안에서 한 칸 아래로 내립니다. 첫 번째 작업물에서 위로, 마지막 작업물에서 아래로는 비활성화될 수 있습니다.
작업물 삭제 선택한 작업물을 삭제합니다. 삭제하면 목록에서 사라집니다. 임시 비공개라면 삭제보다 숨김을 사용하세요.
플레이어 왼쪽 위 설명 공개 페이지 플레이어 왼쪽 위에 글자만 표시되는 설명입니다. 너무 길면 캐릭터 일부와 겹칠 수 있습니다. 1-4줄 정도를 권장합니다.
작업물 정보 바꾸기 이름, 배지, HTML 파일, 소속 그룹, ID 같은 고급 정보를 펼쳐서 수정합니다. 자주 쓰는 설명 입력칸과 분리되어 있습니다. 파일명과 ID는 신중하게 수정하세요.
데이터 확인 현재 포트폴리오 데이터를 JSON 형태로 확인합니다. 읽기 전용 확인용입니다. 일반 편집은 왼쪽 목록과 입력칸에서 하세요.
링크 행의 삭제 추가한 링크 한 줄을 제거합니다. 링크 데이터만 삭제합니다. 작업물 자체는 삭제하지 않습니다.

8. 작업물 정보 바꾸기 안의 항목

항목 의미 작성 팁
작업물 이름 공개 페이지 제목과 왼쪽 목록에 보이는 이름입니다. 아티스트가 보여주고 싶은 이름을 그대로 쓰면 됩니다.
표시 배지 목록 오른쪽에 작게 붙는 짧은 표시입니다. 예: LD, SD, IK, Scene, Boss처럼 짧게 쓰는 것이 좋습니다.
HTML 파일 실제로 로드할 Spine 플레이어 HTML 파일 이름입니다. 대소문자와 언더바까지 정확해야 합니다. 예: Narin.html, Narin_IK.html
소속 그룹 작업물이 들어갈 그룹을 바꿉니다. 변경하면 왼쪽 목록 위치도 해당 그룹으로 이동합니다.
역할 작업에서 맡은 역할을 적는 데이터입니다. 현재 공개 화면에는 크게 표시하지 않습니다. 향후 확장용으로 사용할 수 있습니다.
연도 작업 연도입니다. 예: 2024, 2025
태그 검색이나 분류에 쓸 수 있는 키워드 데이터입니다. 쉼표로 구분합니다. 예: character, idle, combat
ID (고급) 작업물을 구분하는 고유 이름입니다. 중복되면 안 됩니다. URL에도 들어갈 수 있으니 영어와 숫자 위주가 안전합니다.
공개 페이지에서 숨김 체크하면 공개 페이지에서 이 작업물을 숨깁니다. 데이터는 남아 있습니다. 다시 공개하려면 체크를 해제하세요.
링크 추가 작업물에 관련 링크 데이터를 추가합니다. 현재 공개 화면에는 링크 표시 영역을 크게 쓰지 않습니다. URL은 https://로 시작하는 전체 주소를 권장합니다.

9. 자주 하는 작업

작업물 설명 바꾸기

  1. 왼쪽 목록에서 작업물/캐릭터를 클릭합니다.
  2. 플레이어 왼쪽 위 설명 칸에 글을 씁니다.
  3. 오른쪽 저장 상태가 자동 저장 준비 또는 자동 저장 완료 상태인지 확인합니다.
  4. 보기를 눌러 공개 화면에서 글자가 보이는지 확인합니다.

새 작업물 추가하기

  1. 왼쪽에서 넣고 싶은 그룹을 먼저 클릭합니다.
  2. 작업물 추가를 누릅니다.
  3. 작업물 정보 바꾸기를 열어 이름, HTML 파일, 배지를 수정합니다.
  4. 설명 칸에 공개 설명을 적습니다.

그룹 이름 바꾸기

  1. 왼쪽에서 그룹 헤더를 클릭합니다.
  2. 가운데 그룹 정보 레이어에서 그룹 이름을 수정합니다.
  3. 필요하면 그룹 설명과 숨김 여부도 수정합니다.

작업물 순서 바꾸기

  1. 왼쪽에서 작업물을 클릭합니다.
  2. 가운데 위로 또는 아래로 버튼을 누릅니다.
  3. 왼쪽 목록의 순서가 바뀌었는지 확인합니다.

임시로 숨기기

  1. 숨길 그룹 또는 작업물을 선택합니다.
  2. 공개 페이지에서 숨김을 체크합니다.
  3. 다시 보여주려면 체크를 해제합니다.

GitHub Pages에 올리기

  1. 관리자에서 지금 저장을 누릅니다.
  2. 브라우저에서 공개 화면을 확인합니다.
  3. 실행 파일\publish-portfolio.bat를 더블클릭합니다.
  4. 검은 창에 Published 메시지가 나오면 기다립니다. GitHub Pages 반영에는 시간이 조금 걸릴 수 있습니다.

10. 공개 포트폴리오 화면 버튼

버튼/영역 역할 주의점
왼쪽 작업물 목록 작업물을 선택해서 플레이어에 띄웁니다. 숨김 처리된 그룹/작업물은 보이지 않습니다.
새로고침 아이콘 현재 선택된 Spine HTML을 다시 로드합니다. 애니메이션이 멈췄거나 캔버스가 이상할 때 사용합니다.
새 창 아이콘 현재 Spine HTML을 새 탭으로 엽니다. 작품 하나만 크게 확인하고 싶을 때 사용합니다.
플레이어 왼쪽 위 설명 관리자에서 입력한 작업물 설명이 글자만 표시됩니다. 설명이 너무 길면 플레이어 일부와 겹칠 수 있습니다. 필요한 만큼만 짧게 쓰는 편이 좋습니다.

11. 꼭 지켜야 할 주의점

  • admin.html을 직접 더블클릭해서 열지 마세요. 자동 저장이 제대로 되지 않을 수 있습니다. 반드시 실행 파일\edit-portfolio.bat로 여세요.
  • 저장 상태를 확인하세요. 자동 저장 중에는 바로 창을 닫지 말고 잠시 기다리세요.
  • HTML 파일 이름은 정확해야 합니다. GitHub Pages에서는 대소문자 차이도 문제가 될 수 있습니다.
  • ID는 중복되면 안 됩니다. ID는 화면에 크게 보이는 이름이 아니라 데이터 내부 고유값입니다.
  • 삭제는 되돌리기 어렵습니다. 잠깐 안 보이게 할 목적이면 삭제하지 말고 숨김을 사용하세요.
  • publish-portfolio.bat는 data/portfolio.json 변경만 게시합니다. 코드나 레이아웃 변경은 개발자가 별도로 커밋해야 합니다.
  • GitHub Pages 반영은 즉시가 아닐 수 있습니다. push 후 몇 분 정도 기다린 뒤 새로고침하세요.

12. 저장 상태 읽는 법

메시지 의미 해야 할 일
자동 저장 준비됨 저장할 변경사항이 없거나, 저장 가능한 정상 상태입니다. 그대로 작업해도 됩니다.
자동 저장 대기 중 방금 수정한 내용이 잠시 후 저장될 예정입니다. 창을 바로 닫지 말고 잠깐 기다리거나 지금 저장을 누릅니다.
저장 중 편집기가 data/portfolio.json에 쓰는 중입니다. 완료될 때까지 서버 창과 브라우저를 닫지 않습니다.
오류/경고 ID 중복, 파일명 누락, 서버 연결 문제 같은 문제가 있을 수 있습니다. 오른쪽 저장 상태 목록의 문장을 먼저 읽고, 해당 항목을 고친 뒤 다시 저장합니다.

13. 문제가 생겼을 때

상황 확인할 것
저장이 안 되는 것 같다 edit-portfolio.bat로 열었는지, 서버 창이 켜져 있는지, 오른쪽 저장 상태에 오류가 없는지 확인합니다.
작업물이 로드되지 않는다 작업물 정보의 HTML 파일 이름이 실제 파일 이름과 완전히 같은지 확인합니다.
공개 페이지에 안 보인다 그룹이나 작업물이 숨김 처리되어 있는지 확인합니다.
